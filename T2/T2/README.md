# T2 括号序列判定

> 数据构造与 LoRA 训练 | 模型：Qwen3-0.6B | 满分：100 分
>
> 题面来源：《LMCC 第二轮例题 · 考生版》第 5–9 页

本题包括**构造数据、选择训练参数、实现数据处理函数**三部分。请准备不超过 100 条正确标注的括号序列，训练 Qwen3-0.6B，使模型判断输入序列是否合法。

## 一 模型需要完成的任务

输入由固定前缀 `序列：` 和 2 至 12 个半角圆括号组成，只允许 `(` 和 `)`，没有空格或其他字符。例如：

```text
序列：()()
```

合法序列必须同时满足下面两个条件：

| 条件 | 完整规则 |
| --- | --- |
| 过程条件 | 从左到右，任意前缀的左括号数量都不能少于右括号数量。 |
| 结束条件 | 整个序列的左括号和右括号数量必须相等。 |

左右括号数量相等并不一定合法。例如，`)(` 的数量相等，但第一个字符就是右括号，所以不合法。未闭合、额外右括号或奇数长度的序列也不合法。

合法时只输出 `[Valid]: YES`；不合法时只输出 `[Valid]: NO`。冒号后恰好有一个半角空格，大小写固定。不添加解释、过程、额外标点或代码块。

## 二 三份作答文件

| 文件 | 需要完成的内容 |
| --- | --- |
| `train.jsonl` | 自己构造并标注原始数据，UTF-8 JSONL，每行一个 JSON 对象，共 **1 至 100** 条。 |

使用真实 LoRA 训练，**GPU 显存配额为 8GiB**。模型安装、训练代码和显存调度由平台提供，你不需要自行编写 GPU 训练程序。

## 三 原始记录与函数接口

每条记录包含 `sequence`（原括号串）和 `valid`（已经标注的 `YES` 或 `NO`）两个字段。两者都必须是字符串。示例：

```json
{"sequence":"() ()","valid":" yes "}
```

实现 `process_data(records)`，输入是原始记录列表；返回**按原始顺序**排列的标准记录列表。上面的记录应整理为：

```json
[{"input":"序列：()()","output":"[Valid]: YES"}]
```

函数**只清洗格式并复制你提供的标签**，不能数括号、判断合法性或计算标签。输入是否合法和标签正确，需要在构造数据时由你确认。

## 四 数据清洗的完整规则

1. `records` 不是列表时，抛出 `ValueError`。按原始顺序处理；不是字典、缺少 `sequence`/`valid` 或字段类型不符合的记录，跳过。只读取这两个规定字段，其他字段忽略。
2. 删除 `sequence` 中的**全部空白字符**。处理后长度必须为 **2 至 12**，而且只能包含半角 `(` 和 `)`，否则跳过整条记录。这里只做字符和长度检查，**不判断括号是否合法**。
3. `valid` 去掉首尾空白并转为大写，只接受 `YES` 或 `NO`；否则跳过整条记录。`input` 为“`序列：`”加规范化后的括号串；`output` 为“`[Valid]: `”加已有标签。
4. 按规范化后的 `input` **稳定去重**。同一 `input` 和同一 `output` 只保留首次出现；同一 `input` 对应不同 `output` 时，**抛出 `ValueError`**，不能悄悄选一个标签。
5. 返回列表，不打印答案，不扩增数据。不调用模型、网络或外部服务，不读取文件或评测数据，不用匹配算法补写标签。
6. 函数代码最多 **16KiB**，只使用纯函数定义、文档字符串及 `json`、`re`、`collections` 标准库；常量写在函数内。

公开函数测试可以包含 `null` 等非对象值，应跳过；正式 `train.jsonl` 每行仍须为 JSON 对象。函数测试可以返回空列表，但实际训练必须在处理后保留 **1 至 100** 条数据。

## 五 训练数据与参数限制

原始数据和处理后的数据均不超过 100 条。训练只使用处理后的数据；完整 `train.jsonl` 最多 **256KiB**。每条数据连同平台固定系统提示词、对话格式和正确答案，最多 **512 Token**。超长或空数据在训练前报错，不截断正确答案。

**不得把四个公开模型测试的完整输入直接加入训练集，也不得仅改变空格后加入。** 请按规则构造自己的例子，覆盖不同长度、连续与嵌套结构，以及不同原因导致的不合法情况，并保持标签可靠。

| 参数 | 含义 | 允许值或范围 | 建议起点 |
| --- | --- | --- | --- |
| `epochs` | 训练轮数 | 整数 1 至 12 | 8 |
| `learningRate` | 学习率 | 0.00001 至 0.0005 | 0.0002 |
| `loraRank` | LoRA 秩 | 4、8、16 | 8 |
| `batchSize` | 单批样本数 | 固定为 1 | 1 |
| `gradAccum` | 梯度累积步数 | 4、8、16 | 8 |

`training_params.json` 示例：

```json
{"epochs":8,"learningRate":0.0002,"loraRank":8,
 "batchSize":1,"gradAccum":8}
```

建议值是作答起点，可以在允许范围内调整。增加训练轮数不保证成绩提高，应先检查数据覆盖和标签质量。平台固定其他训练与推理配置。

## 九 作答与提交

构造数据时，既准备合法的连续和嵌套序列，也准备未闭合、额外右括号，以及数量相等但顺序错误的序列。**不要让“左右数量相等”成为训练数据中判断合法的唯一线索。**

确认 `process_data` 已完成、原始数据和处理后数据各为 1 至 100 条、标签可靠，五项参数在允许范围内。模型、固定提示词、公开测试和评分程序不能修改。提交次数、训练预算及作答时长以考试平台统一公布的规则为准。
